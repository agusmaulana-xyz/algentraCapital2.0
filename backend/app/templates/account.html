Pasang EA Copy Trading

Petunjuk ini berlaku untuk akun yang memilih menjalankan EA sendiri. Akun yang dikelola server tidak perlu mengikuti langkah MT5 ini di komputer client.

Unduh source EA Copy Trading
  1. Hubungkan akun Copy Trading di atas. Salin token yang muncul; token hanya terlihat saat dibuat atau dirotasi.
  2. Di MT5, pilih File → Open Data Folder, buka folder MQL5/Experts, lalu salin file .mq5 yang diunduh ke sana. Buka file itu di MetaEditor dan tekan F7; hasil compile .ex5 siap digunakan di folder tersebut.
  3. Di MT5, pilih Tools → Options → Expert Advisors, aktifkan Allow WebRequest for listed URL, lalu tambahkan http://127.0.0.1:8000.
  4. Dari Navigator → Expert Advisors, pasang EA Copy Trading di chart. Isi AccountToken dengan token akun tersebut, pastikan ServerURL berisi http://127.0.0.1:8000, lalu aktifkan Algo Trading. MT5 harus berjalan di komputer yang sama dengan backend agar alamat localhost ini terjangkau.
  5. Pastikan EA utama Algentra aktif. EA Copy Trading akan menyalin posisi live saat izin trading MT5 aktif; atur VolumeMultiplier sesuai kebutuhan sebelum menjalankannya.

Arti pesan di chart MT5

HTTP -1 / ERROR 4006: EA belum mendapat jawaban dari server. Kode 4006 berarti MT5 menemukan data array yang tidak valid saat EA berjalan; pesan ini sendiri belum membuktikan token salah. Pastikan URL ServerURL sama dengan alamat yang diizinkan di Allow WebRequest. Jika masih muncul, kirim tangkapan tab Experts kepada dukungan. Jangan kirim token.

TRADING OFF: Periksa Algo Trading serta izin trading terminal, akun, dan Expert Advisor di MT5.

Akun Copy Trading harus memakai mode hedging. Volume salinan mengikuti volume sumber dikalikan VolumeMultiplier; nilainya tidak menyesuaikan ekuitas secara otomatis. Jika pembaruan dari akun utama terhenti lebih dari 20 detik, sinkronisasi berhenti. Posisi yang sudah terbuka tetap berada di MT5 jika EA berhenti.

Jangan bagikan token EA. Jika token hilang atau terekspos, pilih Rotasi token dan perbarui token di EA Copy Trading.
